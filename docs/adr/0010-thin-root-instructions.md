# Корневые инструкции держим тонкими

`AGENTS.md` — единственный файл, который агент читает при каждом запуске, поэтому каждая его строка оплачивается в каждой сессии, включая те, где Менеджер просто просит перегруппировать запросы. Держим его в пределах сотни строк.

В корне остаётся только то, что верно всегда и нарушение чего опасно: перечень Провайдеров, политика записи из [ADR-0009](./0009-asymmetric-write-policy.md), работа с [Реестром](./0008-account-registry-single-source.md), «репозиторий доступен только на чтение», «артефакты отдаются файлом», поведение при протухшем токене. Плюс карта скиллов. Всё остальное — в скиллы: правила Google Ads в `google-ads-context`, правила Яндекса в `yandex-direct-campaign-builder`.

В `direct-mcp-ai-project` корневой файл занимает 24 КБ и содержит правила по каждому Провайдеру. Это работающая цена одного Провайдера с единым meta-layer. У нас Провайдеров четыре, и тот же подход дал бы под сотню килобайт корневых инструкций — объём, на котором агент начинает следовать им выборочно, причём непредсказуемо.

`CLAUDE.md` — симлинк на `AGENTS.md`, а не копия: два файла с одинаковым содержимым расходятся при первой же правке.
